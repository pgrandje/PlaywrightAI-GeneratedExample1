## Copilot (2026-09-24 23:27:49 UTC)

GitHub Copilot is bundled with VS Code as a built-in extension, so it may not appear under the normal installed Marketplace extensions list.

In the Extensions view, try:

- `@builtin copilot`
- `@installed github.copilot`
- `@installed github.copilot-chat`

You can also open **… → Views → Installed** and ensure no search filter is hiding it. The Copilot Chat panel confirms the extension is active even when it is managed as part of VS Code rather than installed separately.
